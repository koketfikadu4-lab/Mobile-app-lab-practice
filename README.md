# Lab1 - Android App

Lab practice for **Elective I - Mobile Application Development**.

## About
A simple Android app (Java) that takes a student's name and phone number and greets them with a Toast message.

## Features
- Title text and image at the top
- Name and phone number input fields (`EditText`)
- Submit button with input validation (shows an error if a field is empty)
- Toast message: "Hello <name> (<phone>)"

## Files
- `MainActivity.java`: app logic (reads the inputs, validates, shows the Toast)
- `activity_main.xml`: screen layout

## How to run
1. Open the project in Android Studio.
2. Make sure the drawable `image1` exists in `res/drawable`.
3. Run on an emulator or a real Android device.
